# Certificazioni LPI

App gratuita, in italiano, per prepararsi all'esame **Linux Essentials** del Linux Professional
Institute (e in seguito a LPIC-1): obiettivi d'esame, lezioni ufficiali in italiano da leggere
anche offline, domande originali con spiegazioni, ripasso e simulazione d'esame.

Il progetto è all'inizio: il piano è in [docs/PIANO.md](docs/PIANO.md).

Le lezioni ufficiali sono del Linux Professional Institute (https://learning.lpi.org), con
licenza [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/deed.it): sono incluse
integrali e non modificate. Domande e spiegazioni sono scritte per questa app.
